# 이세계알파남

이세계로 전이된 평범한 한국 남자가 스탯을 키워 '알파남'이 되는, 육성 + 미연시 하이브리드 웹게임.
세로 모바일 전용 HTML5, **빌드 도구도 서버도 필요 없습니다.**

15세 이용가 · 등장인물은 모두 성인입니다.

## 폴더 구조

```
alphatalk/              ★ 알파톡 — 메신저형 (현재 주력)
alphatalk-solo-backup/  알파톡 3인 개편 이전의 1인 단편 동작본 (보존용)
index.html, js/, css/   v0.2 본편 — 초기 육성형 프로토타입 (보존용)
```

`alphatalk-solo-backup/`과 루트의 v0.2는 **되돌아갈 지점으로 남겨둔 것**이며
현재 개발은 `alphatalk/`에서만 진행됩니다.

---

## 실행

어느 쪽이든 됩니다.

```bash
python -m http.server 5500
```

그 뒤 `http://localhost:5500/alphatalk/` 로 접속합니다.
`alphatalk/index.html`을 브라우저로 직접 열어도 동작하지만,
`file://`에서는 결과 공유의 클립보드 복사가 수동 복사로 대체됩니다.

주소 뒤에 `?debug=1`을 붙이면 개발자 패널이 열립니다.
