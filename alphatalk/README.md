## 배포 방법 (GitHub Pages)

빌드가 필요 없는 정적 파일이라 **이 폴더를 그대로 올리면 끝**입니다.

1. GitHub에서 새 저장소를 만듭니다 (예: `alphatalk`, Public).
2. 이 폴더(`alphatalk/`)의 **내용물 전체**를 저장소 루트에 올립니다.
   ```bash
   cd alphatalk
   git init
   git add .
   git commit -m "이세계알파남 : 알파톡 제1화"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/alphatalk.git
   git push -u origin main
   ```
3. 저장소 → **Settings → Pages** → Source를 `main` 브랜치 `/ (root)`로 지정.
4. 1~2분 뒤 `https://<사용자명>.github.io/alphatalk/` 에서 열립니다.

> HTTPS로 서비스되므로 결과 공유의 클립보드 복사가 정상 동작합니다.
> (로컬 `file://`이나 일부 환경에서는 클립보드 권한이 없어 수동 복사로 대체됩니다.)

## AI 대화 생성 (선택)

타이틀 화면 하단 **고급 설정**에서 본인의 Claude API 키를 넣으면,
엘리시아의 대사와 선택지 3개가 매번 새로 생성됩니다.

- 키가 없어도 게임은 완전히 즐길 수 있습니다 (대화당 최대 5가지 변주 내장).
- 키는 사용자 브라우저의 localStorage에만 저장되며 Anthropic API로만 전송됩니다.
- 사용료는 키 소유자 계정에 청구됩니다 (Haiku 4.5 기준 한 판 약 90원).
- 생성 실패 시 내장 대본으로 자동 폴백되어 게임이 중단되지 않습니다.

## 게임 시스템 요약

- **모든 접촉은 그녀가 먼저** 시작합니다. 플레이어는 답장을 고를 뿐입니다.
- 답장은 **직진 / 재치 / 배려** 세 갈래이며 셋 다 유효합니다.
  다만 **그날 그녀의 기분**과 맞으면 훨씬 깊게 꽂힙니다.
- 낮에는 일과 카드 하나를 고릅니다. 훈련소는 그녀를 직접 봐서 기분 단서를 얻고,
  서고·달빛 정원은 각각 지능·매력을, 알바는 단서 없이 돈만 줍니다.
- 7일차 밤, 건국제 무도회 파트너를 정식으로 신청합니다.
- **엔딩은 세 축의 조합**입니다. 호감도 구간(7종)이 결말을 정하고,
  7일간 가장 많이 고른 **말투**가 "어떤 남자로 기억되는가"를,
  가장 높은 **스탯**이 후일담 한 문단을 결정합니다.
  신청하지 못한 밤에도 호감이 남아 있다면, 관계가 끝나지는 않습니다.

15세 이용가 · 등장인물은 모두 성인입니다.
