# 이미지 넣는 곳

용도는 두 가지입니다 — **엔딩 일러스트**와 **대화 중 그녀가 보내는 사진**.

---

## 대화 중 사진 (이벤트 CG)

대본 어디에나 `photo` 노드 한 줄을 끼우면 그녀가 사진을 보냅니다.
타이핑 인디케이터가 뜬 뒤 사진이 도착하고, 탭하면 전체화면으로 커집니다.

```js
{ e: "아침이다. 기상 시간은 훈련의 절반이다." },
{ photo: "img/ev-duty.jpg", cap: "새벽 근무 교대. 부관이 명부용이라며 굳이 찍었다." },
{ e: "…쓸데없이 잘 나왔다길래 보낸다. 그뿐이다." },
```

- `cap` 은 사진 밑에 붙는 한 줄 설명입니다. 생략해도 됩니다.
- `d` 로 도착 전 뜸 들이는 시간을 조절할 수 있습니다 (기본 900ms).
- **파일이 없으면 그 사진만 조용히 사라지고** 대화는 그대로 이어집니다.

현재 배치: D2 아침 `ev-duty` · D4 아침 `ev-patrol` · D6 아침(d5good) `ev-garden`
미배치 여분: `ev-camp`(야전 붕대) `ev-sunset`(석양) `ev-shy`(실내)

사진은 폭 210px로 표시되니 **세로 2:3**이 가장 잘 맞습니다 (640×960 권장).

# 엔딩 일러스트

이미지를 이 폴더에 넣고 `js/endings.js`의 해당 엔딩에 `art` 한 줄만 추가하면 끝입니다.

```js
truelove: {
  icon: "💞", title: "두 개의 달 아래",
  art: "img/ely-truelove.png",   // ← 이 줄만 추가
  script: [ ... ],
}
```

## 파일명 규칙 (권장)

| 엔딩 | 구간 | 파일명 |
|---|---|---|
| truelove | 호감 90+ | `ely-truelove.png` |
| ok | 80~89 | `ely-ok.png` |
| near | 65~79 | `ely-near.png` |
| fail | 45~64 | `ely-fail.png` |
| stranger | ~44 | `ely-stranger.png` |
| night | 신청 안 함·65+ | `ely-night.png` |
| chicken | 신청 안 함 | `ely-chicken.png` |

전 엔딩에 같은 그림 하나만 쓰려면 `js/heroines.js`의 히로인 항목에
`endingArt: "img/ely.png"` 를 넣으면 됩니다. (엔딩별 `art` 가 있으면 그쪽이 우선)

## 사양

- **가로:세로 3:2 권장** (600×400 이상). 화면에서 최대 폭 300px로 축소되고 모서리가 16px 둥글게 깎입니다.
- png / jpg / webp 아무거나 됩니다.
- 파일이 없거나 깨져도 게임은 안 멈춥니다 — 이미지 자리만 조용히 숨겨지고 이모지 아이콘으로 표시됩니다.
